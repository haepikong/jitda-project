# 배움길 성찰일기

학생이 수업에서 배운 점과 궁금한 점을 기록하고, 교사가 학생 일기에 답장하는 한편 본인 수업도 별도로 돌아볼 수 있는 웹 앱입니다. 학급 코드와 과목은 서버에서 공동 관리되어 같은 서버 주소를 쓰는 여러 선생님과 학생에게 실시간으로 공유됩니다.

## 실행하기

1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 `npm start`를 실행합니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다.

별도 패키지 설치는 필요하지 않습니다. 학생 로그인에서 `예시 화면 체험하기`를 누르면 체험용 코드 `TRY-CLASS`로 샘플 성찰일기와 답장을 살펴볼 수 있습니다. 학생은 학급 코드를 입력하면 등록된 학급과 과목을 확인하고 입장합니다. 교사는 `학급·과목 관리`에서 공용 과목을 선택한 뒤 학년, 시작 반 번호, 학급 수를 입력해 학급 코드를 만들거나, 학급 이름과 코드를 직접 입력해 새 학급을 만들 수 있습니다. 학급 카드의 `코드 복사`로 코드를 학생에게 전달할 수 있습니다. 학생의 `나의 배움 기록`과 교사의 `학생 성찰일기 관리`에서는 기간별 검색을 할 수 있습니다. 체험 중 새로 쓴 일기는 화면 안에서만 연습용으로 남습니다. 현재 학급에서는 과목을 여러 개 체크해 한 번에 삭제할 수 있으며 해당 반에만 적용됩니다. `수업 참고 요약`에서는 학생 기록의 배움 주제와 궁금증, 다음 목표를 수업 전에 참고할 수 있습니다. `교사 수업 성찰기록 관리`에서는 수업 음성을 받아쓰거나 직접 입력하고, 분석 초안을 토대로 본인 성찰을 작성해 저장할 수 있습니다. 음성 녹음 파일은 저장하지 않습니다. 교사 시제품 비밀번호는 `info2026`입니다.

## 데이터와 개인정보

학급, 과목, 성찰일기, 수업 받아쓰기, 교사 성찰, 답장, 칭찬 스티커는 서버 메모리에 보관되며 서버가 다시 시작되면 삭제됩니다. 교사 성찰 분석은 키 없이 동작하는 시제품용 문장 패턴 분석이며 외부 AI 모델 분석은 아닙니다. 음성은 브라우저에서 받아쓰기만 하며 녹음 파일은 저장하지 않습니다. 칭찬 스티커 3장·5장·10장에 따라 칭찬콩 배지·배움 응원 쿠폰·성장왕 배지가 열립니다. 교사 비밀번호는 시제품용이며, 실제 수업에서는 안전한 계정 인증과 학교 정책에 맞는 저장·보관 방식을 적용해 주세요. 민감한 개인정보는 기록하지 마세요.
